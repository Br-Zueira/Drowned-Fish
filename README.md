# Drowned-Fish
A simple 2D troll game made with Love2D. The name is a thing as impossible as you beating this game.

## Requirements
To play: none (except if you want to play the .love universal version, which needs Love2D installed) 
To compile:
Bash (optional, but allows to use the project scripts to make the process more simple and practical)

### To Windows
Zip, Windows standalone Love2D 64 bits

### To Linux
Zip, Appimagetool, Love2D x86_64 official Appimage
