# Drowned-Fish
A simple 2D troll game made with Love2D. The name is a thing as impossible as you beating this game.

## Requirements
### To play:
None (except if you want to play the .love universal version, which needs Love2D installed) 

### To compile:

#### To Windows
Bash, Zip, Windows standalone Love2D 64 bits

#### To Linux
Bash, Zip, Appimagetool, Love2D x86_64 official Appimage

#### Bundle only (universal love format)
Bash, Zip
